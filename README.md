# BearReader

基于 [lightnovel-crawler](https://github.com/lncrawl/lightnovel-crawler) 引擎改造的**单用户中文 Windows 桌面应用**——面向本机管理员个人使用，不面向多用户或公网部署；内置简体中文书源（仅支持中文书源）。把网络小说一键下载为 EPUB / TXT 电子书，支持书名搜索、书架管理、在线阅读与中文朗读。

> 本项目是对上游开源项目 lightnovel-crawler 与 lncrawl-web 的修改与本地化发行（GPL-3.0，许可证见 [LICENSE](LICENSE)，上游来源说明见 [UPSTREAM.md](UPSTREAM.md)）。

本项目由 BearReader 维护者独立维护，与上述上游项目、Microsoft、书源网站及字体作者不存在官方隶属或背书关系。第三方组件及字体继续适用各自许可证，详见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 特性

- **单用户本地应用**：默认只用本机管理员账号，不依赖多用户体系；支持离线使用（朗读与在线搜索除外）
- **绿色版免安装**：解压即用，无需 Python 或任何运行环境；仅需 Win10 x64 + 网络
- **导出 EPUB / TXT**：正文抓取完成后一键生成电子书
- **书架与阅读器**：本地书架分类、内置阅读器（**小熊楷体（默认）、小熊宋体、思源黑体**，自托管离线可用，多种阅读主题可选），支持在线神经语音朗读（9 个中文音色，语速/句间停顿可调，需联网），支持键盘快捷键（方向键切章、空格滚屏、S 开关朗读、+/− 调字号、系统媒体键控制）与自动滚动
- **任务记录管理**：已结束任务可删除/一键清空，运行中任务受保护；取消多步任务（如获取全书）任意一步即取消整个请求
- **继续阅读**：小说详情页一键回到最近阅读章节；支持检查更新并补全缺失章节
- **单实例保护**：重复启动自动等待接管；关闭客户端后进程快速退出
- **任务记录自动清理**：根任务保留 7 天、子任务保留 3 天

## 使用

1. 下载绿色版压缩包 `BearReader-portable-{版本}-{日期}-{时分}.zip`（当前版本见 `lncrawl\VERSION`；常规发版默认只交付绿色 ZIP，安装包仅在明确要求时额外制作）
2. 解压后双击 `BearReader.exe`
3. 在任务请求页粘贴书源 URL 或输入书名 → 获取全书 → 生成导出文件（EPUB / TXT）

支持的书源列表见应用内「书源」页。书名搜索仅个别网站支持，其余书源请先到对应网站找到小说页面 URL 后粘贴。

## 隐私与联网

- 程序默认在本机运行，工作数据保存在 `%APPDATA%\XiaoXiongNovel`；项目维护者不运营公共托管服务，也不默认接收书架、任务或阅读数据。
- 小说搜索和下载会访问用户选择的第三方书源；在线语音朗读会通过 `edge-tts` 将待合成文本和音色参数发送至 Microsoft 在线语音服务。
- 用户主动配置的翻译、邮件、远程 Calibre、代理或数据库服务会按照相应配置联网。不要在配置、日志或问题报告中公开管理员令牌和第三方凭据。

完整说明随前端源代码和发行包提供。将程序自行开放到局域网或互联网时，部署者需要另外承担访问控制、网络安全、备份和隐私告知责任。

## 使用边界

本项目只提供下载、阅读和电子书生成工具，不提供或托管小说内容。使用者应自行确认对目标内容拥有相应权利，并遵守所在地法律、书源网站条款、robots 规则及版权要求。项目内存在某个书源适配器，不代表维护者认可该网站的内容或授权任何特定用途。
