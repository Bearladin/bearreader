隐私与联网说明

BearReader

更新日期：2026 年 8 月 25 日

1. 适用范围

本说明适用于 BearReader Windows 本地发行版及其随附的 Web 客户端。该发行版面向本机个人使用，默认仅在本机启动服务和保存数据；项目维护者不运营面向公众的托管服务，也不会因为您使用本地发行版而自动接收您的书架、任务、小说正文或账户数据。

如果您自行修改配置，将程序部署到局域网、服务器或其他可被第三方访问的环境，您需要自行评估该部署产生的隐私和安全责任。

2. 本地保存的数据

程序可能在 Windows 用户配置目录下的 BearReader 专用数据目录中保存以下内容：

  • 本地配置、数据库和管理员认证信息；
  • 下载任务、书架、阅读位置和阅读设置；
  • 小说正文、封面、缓存、日志和生成的电子书；
  • 用户主动配置的第三方服务地址或凭据。

这些数据默认保存在您的计算机上。请不要把数据目录、配置文件、数据库或日志发送给不受信任的人；提交问题报告前，应先删除其中的令牌、密码、小说正文和其他不希望公开的信息。

桌面启动使用的本地管理员令牌只用于本机客户端与本机后端之间的认证。客户端读取启动令牌后会从地址栏移除它，但您仍应避免公开启动链接、调试日志或本机数据目录。

3. 必要或可选的联网行为

程序本身不建立由项目维护者运营的数据收集通道，但以下功能会直接访问第三方服务：

3.1 小说搜索与下载

当您搜索或下载小说时，程序会向您选择的书源网站发送网络请求。对方可能看到您的 IP 地址、请求时间、目标页面、常规 HTTP 信息以及其自身服务所收集的数据。书源网站的隐私政策和使用条款由其各自制定。

3.2 在线语音朗读

使用在线神经语音朗读时，程序会通过内置语音组件，将待合成的文本、所选音色和相关参数发送至微软的在线语音服务。不要使用该功能朗读不希望发送给第三方的敏感文本。微软对相关请求的处理受其自身隐私声明和服务条款约束。

3.3 用户主动启用的外部服务

如果您自行配置翻译服务、邮件服务、远程电子书转换服务、代理、数据库或其他外部服务地址，相关数据会按照您的配置发送给对应服务。未配置或未启用这些功能时，程序不会代替您使用这些服务。

4. 项目维护者不收集的数据

本地发行版默认不向项目维护者发送遥测、分析事件、书架内容、下载历史、阅读位置或崩溃报告。项目维护者无法远程查看或删除您计算机上的数据。

代码托管平台、书源网站、微软及用户自行配置的其他服务是独立第三方，其数据处理不受本项目控制。

5. 数据管理与删除

您可以在程序中删除任务和书架内容。若要清除本地工作数据，请先退出程序并确认无需保留相关内容，再备份必要的电子书，然后删除 Windows 用户配置目录下的 BearReader 专用数据目录。

删除本地数据不会撤回已经发送给第三方网站或在线服务的网络请求，也不会删除您另行复制到其他位置的电子书、备份或日志。

6. 安全提示

  • 仅从可信来源获取程序和更新，并核对发布方提供的文件校验值；
  • 不要公开本地管理员令牌、配置文件、数据库、代理凭据或日志；
  • 不要加载来源不明的自定义书源代码；
  • 若将服务开放到本机之外，请自行配置网络隔离、访问控制和传输安全。

7. 变更

联网功能或数据保存方式发生实质变化时，本说明应同步更新。历史版本可通过项目版本记录和代码提交历史核对。
